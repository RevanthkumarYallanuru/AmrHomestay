## Interaction States

### Desktop: Hovering on Similar Room
```
Card scales up 5%, shadow increases
Gold accent highlights the title
Opacity on image increases slightly
Cursor indicates clickable
```

### Mobile: Expanding Amenities
```
Height animation from 0 to auto (300ms)
Arrow rotates 180° (300ms)
Content fades in (300ms)
Touch feedback on button
```

### All Devices: Booking Card
```
Desktop: Stays visible while scrolling (sticky)
Tablet: Scrolls naturally with content
Mobile: Positioned after gallery for quick action
```

## Color Scheme

- **Primary Text**: Foreground (#1a2e1a dark or #faf9f6 light)
- **Accent Gold**: #b8860b (prices, highlights, buttons)
- **Secondary**: #faf9f6 (backgrounds, cards)
- **Borders**: #e0e0e0 (subtle dividers)
- **Success Green**: #10b981 (availability badge)
