## Responsive Utilities Used

```css
/* Show/hide by breakpoint */
.hidden.md:block        /* Hide mobile, show desktop */
.md:hidden              /* Show mobile, hide desktop */
.lg:sticky              /* Sticky only on large screens */
.lg:col-span-2          /* 2-column span on desktop */
.lg:col-span-1          /* 1-column span on desktop */
.lg:top-24              /* Sticky offset on desktop */

/* Grid adjustments */
grid-cols-1             /* Mobile: 1 column */
grid-cols-2 md:grid-cols-3  /* Tablet: 2, Desktop: 3 */

/* Typography responsive */
text-3xl lg:text-4xl    /* Smaller mobile, larger desktop */
text-xl lg:text-2xl     /* Responsive heading sizes */
```
